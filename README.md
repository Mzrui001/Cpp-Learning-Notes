# Cpp-Learning-Notes

《C++ Primer Plus》学习心得，以代码和大量注释的形式标注学习过程中的重难点内容。

## 📖 项目简介

本仓库用于记录个人在学习《C++ Primer Plus》过程中的代码实践与笔记。所有的知识点都直接以代码注释的形式融入到了源文件中，方便随时查阅和复习。

## 📂 目录结构

- `main.cpp`：主程序入口文件。
- `Chapter_01_04.cpp`：第 1-4 章的学习笔记代码。
- `Chapter_01_04.h`：第 1-4 章对应的头文件。
- `Cpp Learning Notes.slnx`：Visual Studio 解决方案文件（使用较新版本的 Visual Studio 打开）。
- `Cpp Learning Notes.vcxproj`：Visual Studio 项目文件。
- `.vcxproj.filters` / `.vcxproj.user`：Visual Studio 项目配置和用户设置文件。

## 🛠️ 开发环境

- **IDE**：Visual Studio (推荐 Visual Studio 2022 及以上版本，以支持 `.slnx` 格式的解决方案文件)
- **语言标准**：C++
